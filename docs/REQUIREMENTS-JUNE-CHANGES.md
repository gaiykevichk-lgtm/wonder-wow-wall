## 1. Обзор изменений

### 1.1 Что меняется

| Раздел | Тип изменения | Приоритет |
|--------|---------------|-----------|
| Шапка | Расширение меню | 🟢 Низкий |
| Главная страница | Новый контент, слайдер | 🟡 Средний |
| Каталог | Отображение белых панелей | 🟢 Низкий |
| **Карточка товара** | **Полная переработка UX** | 🔴 Высокий |
| Пространства | Новый контент | 🟡 Средний |
| Просто | Новый контент, аккордеоны | 🟡 Средний |
| Подписка | Новый B2C-контент | 🟡 Средний |
| **Профессионалам** | **Новый B2B-раздел** | 🔴 Высокий |

### 1.2 Ключевые концептуальные изменения

1. **Текстуры вместо цветов** — панели теперь характеризуются текстурами (дерево, кожа, ткань, металл), не только цветом
2. **Встроенный калькулятор** — расчёт стоимости непосредственно в карточке товара
3. **Подписка как философия** — акцент на «стены как сервис», а не разовая покупка
4. **B2B-сегмент** — новый раздел для профессионалов (дизайнеры, подрядчики, проектировщики)
5. **Технологическая роскошь** — новый подход к позиционированию продукта

## 2. Шапка сайта (Header)

### 2.1 Текущая навигация

```
Каталог | Пространства | Конфигуратор | Подписка | Просто | Профессионалам
                                              [Поиск] [Личный кабинет] [Меню]
```

### 2.2 Требуемые изменения

#### 2.2.1 Расширение меню (бургер-меню или основное)

Добавить пункты:
| Пункт | Описание | URL |
|-------|----------|-----|
| Шоу-румы | Страница с шоу-румами | `/showrooms` |
| Портфолио | Галерея реализованных проектов | `/portfolio` |
| О нас | Информация о компании | `/about` |
| Блог | Статьи, новости | `/blog` |
| Контакты | Контактная информация | `/contacts` |

### 2.3 Требования к реализации

| ID | Требование | Тип |
|----|------------|-----|
| HDR-001 | Пункты «Шоу-румы», «Портфолио», «О нас», «Блок», «Контакты» должны быть доступны | Функциональное |
| HDR-002 | При клике на пункт — переход на соответствующую страницу | Функциональное |
| HDR-003 | Активный пункт меню визуально выделяется | UX |
| HDR-004 | Меню корректно отображается на мобильных устройствах | UX |

### 2.4 Дизайн-требования

- Стиль пунктов меню: аналогичный существующим
- Для мобильных: выпадающее меню или бургер-меню
- Поддержка hover-эффектов

## 10. Спецификация калькулятора

### 10.1 Алгоритм расчёта

```python
def calculate_project(height_cm: float, width_cm: float, panel_size: str) -> dict:
    """
    Расчёт проекта
    
    Args:
        height_cm: Высота стены в сантиметрах
        width_cm: Ширина стены в сантиметрах
        panel_size: Типоразмер панели ('300x300', '300x600', '600x600')
    
    Returns:
        {
            'wall_area': float,           # Площадь стены в м²
            'boxes_count': int,           # Количество коробок (округление вверх)
            'actual_area': float,         # Фактический метраж
            'panels_count': int,          # Количество панелей
            'subscription_price': float, # Цена подписки
            'purchase_price': float       # Цена покупки
        }
    """
    
    # Справочник
    PANEL_SIZES = {
        '300x300': {'panels_per_box': 12, 'panel_area': 0.09, 'box_area': 1.08},
        '300x600': {'panels_per_box': 6, 'panel_area': 0.18, 'box_area': 1.08},
        '600x600': {'panels_per_box': 4, 'panel_area': 0.36, 'box_area': 1.44},
    }
    
    # 1. Площадь стены
    wall_area = (height_cm * width_cm) / 10_000
    
    # 2. Количество коробок (с учётом страхового запаса 10%)
    specs = PANEL_SIZES[panel_size]
    boxes_count = ceil(wall_area * 1.1 / specs['box_area'])
    
    # 3. Фактический метраж
    actual_area = boxes_count * specs['box_area']
    
    # 4. Количество панелей
    panels_count = boxes_count * specs['panels_per_box']
    
    # 5. Цены (зависят от типоразмера и политики)
    # subscription_price = get_subscription_price(panel_size)
    # purchase_price = get_purchase_price(panels_count, panel_size)
    
    return {
        'wall_area': round(wall_area, 2),
        'boxes_count': boxes_count,
        'actual_area': round(actual_area, 2),
        'panels_count': panels_count,
        'subscription_price': subscription_price,
        'purchase_price': purchase_price
    }
```

### 10.2 API-спецификация

#### Endpoint: POST /api/calculate

**Request:**
```json
{
  "height": 250,          // Высота в см
  "width": 400,           // Ширина в см
  "panel_size": "300x300", // Типоразмер
  "design_type": "mono"   // "mono" или "combined"
}
```

**Response:**
```json
{
  "success": true,
  "data": {
    "wall_area": 10.0,
    "boxes_count": 11,
    "actual_area": 11.88,
    "panels_count": 132,
    "subscription_price": 4900,
    "purchase_price": 52800
  }
}
```

**Формулы:**
- `wall_area` = (height × width) / 10000
- `boxes_count` = ceil((wall_area × 1.1) / box_area)
- `actual_area` = boxes_count × box_area
- `panels_count` = boxes_count × panels_per_box
