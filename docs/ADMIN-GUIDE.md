# Гайд по админке Wonder Wow Wall

> Вход: **admin@wow.ru** / **admin123**  
> URL: `/admin`

---

## Архитектура каталога

Каталог построен на иерархии из 4 уровней:

```
Категория (размер панели)
  └─ Форма (дизайн рельефа)
       └─ Текстура (материал покрытия)
            └─ Цвет (конкретный оттенок текстуры)
```

**Пример:**
- Категория: **30×30 см**
  - Форма: **Волна**
    - Текстура: **Дерево**
      - Цвет: **Натуральный дуб** (#C4A882)

Управление разделено на два раздела админки:
- **Каталог** (`/admin/catalog`) — категории и формы
- **Текстуры** (`/admin/textures`) — текстуры, цвета и привязка комбинаций

## 1. Управление формами

### Раздел: Каталог → вкладка «Дизайны»

**URL:** `/admin/catalog?tab=designs`

### Добавить новую форму

1. Нажмите **«+ Создать дизайн»** в правом верхнем углу
2. Заполните поля в боковой панели:

| Поле | Описание | Пример |
|------|----------|--------|
| **Название** | Русское имя формы | Волна |
| **Slug** | Генерируется автоматически из названия (латиница) | wav-s |
| **Категория** | Размер панели (30×30, 30×60, 60×60) | 30×30 см |
| **Изображение** | Путь к фото формы или загрузка файла | `/uploads/forms/30x30/wav-s-10-front.png` |
| **Превью** | Силуэт формы (белый на прозрачном) | `/uploads/forms/30x30/wav-s-10-front.png` |
| **Описание** | Текстовое описание формы | Классическая волна — мягкие переливы... |
| **Цена** | Базовая цена формы в рублях | 1200 |
| **Опубликован** | Видимость в публичном каталоге | Вкл |
| **Новинка** | Бейдж «NEW» на карточке | Вкл/Выкл |
| **Хит** | Бейдж «ХИТ» на карточке | Вкл/Выкл |

3. Нажмите **«Сохранить»**

### Редактировать форму

- Нажмите иконку карандаша (✏️) в строке нужной формы
- Измените поля → **«Сохранить»**

### Удалить форму

- Нажмите иконку корзины (🗑) → подтвердите удаление

### Управлять видимостью

- Переключатель **«Опубликован»** в таблице — мгновенное вкл/выкл без открытия формы

## 2. Управление текстурами

### Раздел: Текстуры → вкладка «Текстуры»

**URL:** `/admin/textures`

Текстуры — это материалы покрытия (Кожа, Текстиль, Дерево, Металл и т.д.).

### Добавить текстуру

1. Нажмите **«+ Создать текстуру»**
2. Заполните:

| Поле | Описание | Пример |
|------|----------|--------|
| **Название** | Русское имя материала | Натуральный камень |
| **Slug** | Латинский идентификатор | natural-stone |
| **Порядок** | Число для сортировки (0 = первый) | 4 |
| **Активна** | Доступность текстуры | Вкл |

3. Опционально: загрузите **swatch-изображение** (образец текстуры)
4. Нажмите **«Сохранить»**

### Текущие текстуры

| # | Текстура | Slug |

| 2 | Текстиль | textile |
| 3 | Дерево | wood |
| 4 | Металл | metal |
| 5 | Природный камень | natural-stone |
| 6 | Декоративные фактуры | decorative |
| 7 | Краска | paint |
| 8 | Графика | graphics |

## 3. Управление цветами текстур

### Раздел: Текстуры → вкладка «Цвета»

**URL:** `/admin/textures?tab=colors`

Каждый цвет принадлежит конкретной текстуре.

### Добавить цвет

1. Перейдите на вкладку **«Цвета»**
2. В выпадающем списке выберите **текстуру** (например, «Дерево»)
3. Нажмите **«+ Создать цвет»**
4. Заполните:

| Поле | Описание | Пример |
|------|----------|--------|
| **Название** | Русское имя цвета | Натуральный дуб |
| **HEX** | Цвет в формате HEX (через палитру) | #C4A882 |
| **Порядок** | Число для сортировки | 0 |
| **Активен** | Доступность цвета | Вкл |

5. Опционально: загрузите **swatch-изображение** (фото образца)
6. Нажмите **«Сохранить»**

### Текущие цвета (по 5 на текстуру)

**Кожа:** Шоколад, Карамель, Слоновая кость, Чёрная кожа, Бордо  
**Текстиль:** Лён, Графит, Лаванда, Изумруд, Терракот  
**Дерево:** Натуральный дуб, Тёмный орех, Берёза, Венге, Ясень  
**Металл:** Сталь, Бронза, Золото, Медь, Чернёный  
**Природный камень:** Каррарский мрамор, Серый гранит, Оникс, Травертин, Сланец  
**Декоративные фактуры:** Белая штукатурка, Серый бетон, Терракотовая штукатурка, Песчаник, Антрацит  
**Краска:** Белый, Слоновая кость, Пыльная роза, Серо-голубой, Оливковый  
**Графика:** Монохром, Индиго, Терракот, Золотой орнамент, Изумрудный

## 4. Привязка комбинаций (Variant Images)

### Раздел: Текстуры → вкладка «Изображения комбинаций»

**URL:** `/admin/textures?tab=images`

Эта вкладка связывает **формы** с **текстурами** и **цветами** через конкретные изображения.

### Как это работает

Variant Image — это конкретная фотография панели определённой формы в определённой текстуре и цвете. Например:

> Форма «Волна» + Текстура «Дерево» + Цвет «Натуральный дуб» → фото `wave-wood-oak.jpg`

### Добавить изображение комбинации

1. Перейдите на вкладку **«Изображения комбинаций»**
2. В сетке найдите нужную комбинацию (Форма × Текстура)
3. Для каждого цвета текстуры загрузите соответствующее изображение

### Матрица комбинаций

Полная матрица: **37 форм × 8 текстур × 5 цветов = 1480 комбинаций**

На практике не все комбинации нужны — заполняйте по мере необходимости.

## Типичные сценарии

### Добавить новую форму с нуля

1. **Каталог → Дизайны** → создать форму (название, категория, изображение)
2. **Текстуры → Изображения комбинаций** → загрузить фото формы в нужных текстурах/цветах
3. **Рекомендации** → привязать 3 похожие формы

### Добавить новую текстуру

1. **Текстуры → Текстуры** → создать текстуру (название, slug)
2. **Текстуры → Цвета** → выбрать новую текстуру → добавить цвета (5 рекомендуется)
3. **Текстуры → Изображения комбинаций** → загрузить фото для форм с новой текстурой

### Добавить цвет к существующей текстуре

1. **Текстуры → Цвета** → выбрать текстуру → **«+ Создать цвет»**
2. Заполнить название, HEX, порядок → сохранить
3. При необходимости — загрузить изображения комбинаций для нового цвета
