## 4. Карточка товара (Product Page) — КРУПНЫЕ ИЗМЕНЕНИЯ

Это **центральный элемент** всех правок. Требует существенной переработки.

### 4.1. Базовое отображение (до выбора текстуры)

**Левая часть экрана:**
- Название и описание
- Большая белая панель
- Внизу переключатель ракурсов

**Правая часть экрана:**
- **Материал:** пиктограммы с текстурами
  - При наведении — отображение цены «от ХХ руб./кв.м.»
- **Исполнение:** выбор конкретных вариантов (дерево, металл и т.д.)
- **Размер:** переключатель размеров или фиксированный
- **Стоимость зависит от выбранного решения** (бледным текстом)
- **Кнопка:** Рассчитать проект

### 4.2. После выбора текстуры

**Левая часть:**
- Название и описание
- Большая панель, «одетая» в выбранную текстуру и исполнение
- Внизу — рендеры интерьеров (открываются большими после нажатия), вместо переключателей ракурсов

**Правая часть:**
- Без изменений до блока «Размер»
- После размера:
  - **Стоимость решения: от ХХ руб./кв.м.**
- **Кнопка:** Рассчитать проект

### 4.3. Боковая панель «Рассчитать проект»

**После нажатия кнопки «Рассчитать проект»:**
- Справа плавно выезжает боковая панель
- Пользователь продолжает видеть выбранную панель и текстуру

#### Шаг 1: Размеры
```
Рассчитать проект
Укажите размеры поверхности для точного расчёта стоимости:

Высота: [___________] см
Ширина:  [___________] см
```

#### Шаг 2: Тип дизайна
- **По умолчанию:** моно-дизайн (вся стена из 1 типа панелей)
- **Опция:** комбинированный дизайн (выбор нескольких типов панелей)

#### Шаг 3: Расчёт

**Ваш проект:**
| Параметр | Формула |
|----------|---------|
| Площадь стены | Высота × Ширина (в кв.м.) |
| Количество коробок | ⌈Площадь × 1.1 / Площадь коробки⌉ (округление вверх) |

**Справочник типоразмеров:**
| Типоразмер | Панелей в коробке | Площадь 1 панели | Площадь коробки |
|------------|-------------------|------------------|-----------------|
| 300×300 мм | 12 | 0.09 кв.м. | 1.08 кв.м. |
| 300×600 мм | 6 | 0.18 кв.м. | 1.08 кв.м. |
| 600×600 мм | 4 | 0.36 кв.м. | 1.44 кв.м. |

**Отображение результатов:**
- Фактический метраж (с подписью: «Мы учли технологический запас»)
- Точное количество панелей в штуках
- **Подписка:** ХХХ руб./месяц + «Одна бесплатная замена в год включена»
- **Покупка:** ХХХХ руб.

**Кнопки:**
- Оформить подписку
- Купить

### 4.4. Технические характеристики (новый блок)

**Раскрывающийся список:**
| Параметр | Значение |
|----------|----------|
| Размер панели | 300×300 мм (динамический) |
| Толщина | 3 мм |
| Исполнение | Архитектурное декоративное покрытие (или «Интерьерная кожа» / «Интерьерная ткань») |
| Система монтажа | Запатентованная система быстрой замены |
| Основа | Ультралёгкий композит высокой плотности |
| Упаковка | 12 панелей – 1,08 м² (динамический) |

### 4.5. Блок «Компаньоны»

- Пользователь может полистать панели аналогичного размерного ряда
- Панели, которые могут сочетаться с выбранной

### 4.6. CTA внизу карточки

**Кнопка:** «Ваш интерьер начинается здесь.»
**Действие:** Переход в Конфигуратор для фотографирования стены и примерки панели

### Три блока преимуществ

#### Свобода действий. Начните сейчас.
```
Традиционный ремонт требует крупных единовременных вложений.
Мы превращаем их в комфортные регулярные платежи.
Интерьер становится доступен сразу, без необходимости откладывать реализацию проекта на годы вперёд.
```

#### Свобода решений. Право передумать.
```
Интерьер больше не обязан оставаться неизменным только потому, что когда-то был выбран.
Если дизайн перестал вдохновлять или изменились задачи пространства, его можно обновить без нового ремонта.
Одно комплексное обновление интерьера ежегодно уже включено в программу обслуживания.

```
Подписка не создаёт кредитной нагрузки и не требует долгосрочных финансовых решений.
Вы пользуетесь сервисом ровно столько, сколько он нужен именно Вам.

## Технические задачи

### Backend (если ещё не реализовано)
1. **API для расчёта стоимости:**
   - `POST /api/calculate` — расчёт площади, количества коробок, панелей
   - Формула: `⌈(height × width / 10000) × 1.1 / box_area⌉`

2. **API для подписки:**
   - Интеграция с платёжной системой
   - Управление подпиской

### Frontend
1. **Новый компонент «Калькулятор проекта»:**
   - Боковая панель с пошаговым вводом
   - Автоматический расчёт при вводе размеров
   - Отображение результатов: площадь, коробки, стоимость

2. **Компонент «Технические характеристики»:**
   - Раскрывающийся список
   - Динамические значения на основе выбранного типоразмера

3. **Компонент «Аккордеон» для блоков «+»:**
   - Анимация раскрытия
   - Поддержка вложенного контента

4. **Новая страница «Профессионалам»:**
   - Компоненты для B2B-контента
   - Возможно, отдельный лейаут

### Дизайн
1. Обновить стили цитат
2. Создать иконки для материалов/текстур
3. Подготовить визуалы для сэндвич-анимации
4. Создать баннеры/изображения для новых страниц

## Резюме

Документ описывает **комплексный редизайн** e-commerce-проекта с акцентом на:

1. **Улучшение UX карточки товара** — интерактивный выбор текстур, встроенный калькулятор
2. **Расширение контент-стратегии** — новые страницы и блоки для B2B/B2C
3. **Обновление визуального языка** — новые слайды, цитаты, технические характеристики
4. **Новый B2B-сегмент** — страница для профессионалов с экосистемой поддержки

Для реализации потребуется:
- **Frontend:** 2-3 спринта (новые компоненты, переработка карточки)
- **Backend:** 1-2 спринта (API калькулятора, интеграция подписки)
- **Дизайн:** 2-3 спринта (новые макеты, иконки, ассеты)
- **Контент:** 1 спринт (тексты, фото/видео материалы)
