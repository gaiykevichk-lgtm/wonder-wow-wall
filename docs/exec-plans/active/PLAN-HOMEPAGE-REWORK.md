## Дизайн-система

### Фирменные цвета и элементы

| Элемент | Значение | Примечание |
|---|---|---|
| Логотип | Зелёный логотип | Не менять, использовать существующий |
| Шрифт | Apple (Inter/system) | Использовать `font-family: Inter, -apple-system, system-ui` |
| ACCENT | `#4CAF50` | Зелёный для CTA и акцентов |
| ACCENT_DARK | `#2E7D32` | Hover, градиенты |
| DARK | `#2D2D2D` | Основной текст |
| GRAY_TEXT | `#6B7280` | Вторичный текст |

### UI/UX Pro Max

Перед каждой фазой — поиск релевантных стилей:

```bash
python3 ~/.claude/skills/ui-ux-pro-max/scripts/search.py "<запрос>" --domain <домен>
```

**Применять для:**
- `style` → чистый minimal visual, bento grid
- `color` → фирменная палитра Wonder Wow Wall (не добавлять новые)
- `typography` → Inter/system fonts
- `ux` → accessibility, animation timing
- `react` → inline styles, Framer Motion

## Фаза 6: "Ваш проект. В деталях" (слайд 6)

**Цель:** Добавить секцию с тремя блоками: калькулятор, сценарии, виртуальная примерка.

### 6.1 Frontend

**Файл:** `frontend/src/domains/content/ui/HomePage.tsx` → новая `ProjectDetailsSection`

**Три блока:**

1. **Точный расчёт**
   - Минималистичный калькулятор: высота (м) + длина (м) → площадь (м²)
   - Система определяет количество панелей и цену от
   - InputNumber для высоты и длины, авторасчёт площади
   - Результат: "X панелей, от Y ₽"

2. **Сценарии жизни**
   - Сетка визуализаций: гостиная, спальня, зона ТВ, детская, кухня, WC
   - Миниатюры с подписями
   - Клик → переход к сценарию в каталоге или конструкторе

3. **Виртуальная примерка**
   - Заголовок: "Готовы увидеть это на своей стене?"
   - Описание: загрузите фото и посмотрите как изменится Ваш интерьер
   - CTA: **"[ WOW! ]"** → `/visualizer` (photo editor)

**Изменения:**

- [ ] Создать `ProjectDetailsSection`
- [ ] Layout: 3 колонки (calculator | scenarios | virtual fitting)
- [ ] Калькулятор: input height + length → auto-calculated area → approximate panel count + price
- [ ] Сценарии: горизонтальный scroll или grid из 6 thumbnail'ов
- [ ] Виртуальная примерка: CTA с иконкой → `/visualizer`

### 6.2 Backend

- [ ] Если отсутствует — создать простой endpoint `POST /api/quick-calculate` (height_m, length_m → panels_estimate, price_from)

### 6.3 Тесты
