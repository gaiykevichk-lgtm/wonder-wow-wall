## Шаги реализации

### Фаза 1 — Контентная целостность (SPC-08, SPC-11)
1. **spacesData.ts**: перестроить `textures[]` каждого интерьера так, чтобы все варианты фактур ссылались на изображение ТОЙ ЖЕ сцены (`image` интерьера). Убрать подмену фото других комнат. Подписи/свотчи отражают выбранный вариант; сами per-scene рендеры под разные фактуры — контентная задача Q05 (структура данных уже готова их принять).
2. **3d-parallax-unfurling-gallery.tsx**: убрать декоративные границы внутри hero (`border border-white/10` у стеклянной карточки контента, `border-white/15` у бейджа) — SPC-11.

### Фаза 2 — URL-синхронизация фильтров (приёмка, [Р])
3. **SpacesPage.tsx**: фильтры ↔ `useSearchParams`: `cat`, `room`, `zone`, `style`, `texture`. Чтение при маунте (восстановление), запись при изменении (`replace: true` для сброса зависимых).
4. Смена назначения сбрасывает `room`/`zone` в URL (сейчас только в state). Пустой результат — существующий блок сброса без перезагрузки (уже есть, проверить сброс также `zone`).
5. Возврат на страницу восстанавливает фильтры из URL + опционально скролл к секции каталога (`sessionStorage` флаг возврата).

### Фаза 3 — Контекстный переход в карточку (ТЗ-19, SPC-07)
6. **SpacesPage.tsx**: navigate в карточку с query `?interiorId=<id>&variantId=<textureId>` (из модалки — с выбранной фактурой).
7. **CatalogPanelPage.tsx**: читать `interiorId`/`variantId`: бейдж «Из интерьера: <title>» + предвыбор текстуры/панели по variantId; кнопка «назад к пространствам» сохраняет фильтры (URL уже хранит).
8. **Модалка «переодевания»**: блок быстрой смены панели — свотчи связанных панелей интерьера (новое поле `relatedPanels: {slug,name,preview}[]` в spacesData); выбор меняет target CTA «Перейти в карточку панели».

### Фаза 4 — Состояния данных ([Р], SPC-09)
9. Вынести `SPACES_DATA` в `public/content/spaces.json`; в SpacesPage fetch с состояниями: skeleton-загрузка, ошибка + «Повторить», пусто, успех.
10. Тест целостности данных: уникальность id, непустые сцены, отсутствие дублей сцен, textures[] одной сцены (SPC-09).

### Фаза 5 — Доступность и анимация (SPC-10, SPC-12, приёмка)
11. Группы фильтров: roving tabindex + стрелки ←/→, `aria-pressed` на чипах, видимый focus-ring; в модалке свайп и стрелки для переключения фактур.
12. Hero: `useReducedMotion` — при prefers-reduced-motion контент виден сразу без unfurling.
13. SPC-12: триггер раскрытия — завершение жеста скролла (onScrollEnd/debounce ~150ms), анимация доигрывает до конца (не обрывается на новом скролле).

### Фаза 6 — Проверка и релиз
14. Тесты: URL-restore, сброс зависимых фильтров, переход с variantId, empty-state сброс.
15. `npm run build`, прогон витеста, деплой на прод.
16. Визуальная проверка 360px и 1440px: фильтры не перекрывают изображения, CTA различимы; hero без рамок.
