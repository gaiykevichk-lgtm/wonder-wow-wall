## Быстрый цикл разработки

### 1. Локальная разработка
```bash
cd frontend
npm install
npm run dev -- --host
# Открыть http://localhost:3000
```

### 2. Сборка после изменений
```bash
cd frontend
npm run build
```

### 3. Деплой на прод
```bash
# Скопировать собранные файлы
scp -i ~/.promto/deploy-keys/api-df334114 \
  -r frontend/dist/* \
  root@72.56.37.191:/opt/app/frontend/dist/
```

### 4. Или одной командой
```bash
npm run build && \
scp -i ~/.promto/deploy-keys/api-df334114 \
  -r frontend/dist/* \
  root@72.56.37.191:/opt/app/frontend/dist/
```

## Бэкенд (если нужны правки API)

**Бэкенд на проде:**
- Контейнер: `app-backend-1`
- Перезапуск: `docker restart app-backend-1`

**Основные файлы API:**
| Описание | Файл |
|---------|------|
| Публичное API | `backend/app/infrastructure/api/catalog.py` |
| Админ API | `backend/app/infrastructure/api/admin/` |
| Use Cases | `backend/app/application/catalog/` |

**Деплой бэкенда:**
```bash
# Скопировать файл
scp -i ~/.promto/deploy-keys/api-df334114 \
  backend/app/container.py \
  root@72.56.37.191:/tmp/

# Вставить в контейнер
ssh -i ~/.promto/deploy-keys/api-df334114 root@72.56.37.191 "
  docker cp /tmp/container.py app-backend-1:/app/app/container.py
  docker restart app-backend-1
"
```

## Troubleshooting

**Фронтенд не обновился:**
- Очисти кэш браузера: Ctrl+Shift+R
- Проверь что файлы скопировались: `ls /opt/app/frontend/dist/`

**Бэкенд упал:**
- Проверь логи: `docker logs --tail 30 app-backend-1`
- Перезапусти: `docker restart app-backend-1`

**Ошибка 404 на API:**
- Проверь что бэкенд запущен: `curl http://localhost:8080/api/panels`
