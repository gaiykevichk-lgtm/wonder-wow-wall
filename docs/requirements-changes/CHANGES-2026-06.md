### 4.3 Модальное окно «Рассчитать проект»

> При нажатии кнопки справа плавно выезжает боковая панель. Пользователь остаётся на той же странице.

#### Шаг 1. Ввод размеров
| Элемент | Описание |
|---------|----------|
| Заголовок | Рассчитать проект |
| Подзаголовок | Укажите размеры поверхности для точного расчёта стоимости: |
| Поля | Высота; Ширина |

#### Шаг 2. Выбор дизайна
| Режим | Описание |
|-------|----------|
| **Моно-дизайн** (по умолчанию) | Вся стена из одного типа панелей |
| **Комбинированный дизайн** | Пользователь выбирает все интересующие типы панелей |

#### Шаг 3. Расчёт проекта

**Автоматический расчёт после ввода размеров:**

| Параметр | Формула/Значение |
|----------|------------------|
| Площадь стены | Высота × Ширина |
| Количество коробок | `⌈(Площадь × 1.1) / Площадь коробки⌉` |

**Справочник типоразмеров:**

| Типоразмер | Панелей в коробке | Площадь 1 панели | Площадь коробки |
|------------|-------------------|------------------|-----------------|
| 300×300 мм | 12 шт. | 0,09 кв.м. | 1,08 кв.м. |
| 300×600 мм | 6 шт. | 0,18 кв.м. | 1,08 кв.м. |
| 600×600 мм | 4 шт. | 0,36 кв.м. | 1,44 кв.м. |

**Отображение результатов:**

| Параметр | Описание |
|----------|----------|
| Площадь стены | Математическое значение |
| Количество коробок | Округлённое в большую сторону |
| Фактический метраж | Площадь от полученных коробок + подпись: «Мы учли технологический запас» |
| Точное количество панелей | В штуках |

**Два предложения:**

| | Подписка | Покупка |
|---|----------|---------|
| Цена | ххх руб./месяц | хххх руб. |
| Кнопка | Оформить подписку | Купить |
| Подпись | Одна бесплатная замена в год включена | — |

### Б. Технические параметры панелей

| Параметр | Значение |
|----------|----------|
| Типоразмеры | 300×300, 300×600, 600×600 мм |

### В. Формула расчёта

```
Количество коробок = ⌈(Площадь стены × 1.1) / Площадь коробки⌉
```

Где 1.1 — коэффициент страхового запаса на обрезку.
