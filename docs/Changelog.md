## 08.04.2026

### Фоторедактор стен v2: код-ревью и исправления

Проведён детальный код-ревью всех 5 фаз фоторедактора. Выявлено и исправлено 8 критических и 14 некритических проблем:

- **Сегментация**: устранена утечка singleton-кэша при ошибке инициализации модели, добавлены таймауты загрузки модели (60 сек) и инференса (30 сек), добавлена обработка пустых результатов сегментации
- **Утечка памяти**: Object URL в `createImageFromFile` не освобождался после загрузки — исправлено
- **WallCanvas**: клик `onCanvasClick` срабатывал во всех режимах размещения — теперь только в `manual`
- **CostSummary**: захардкоженные цены панелей (890, 1490, 2490) заменены на константы из `BASE_PANEL_PRICES`
- **PlacementControls**: CTA-кнопка «Заполнить стену» приведена к Design System — тёмный фон `#2D2D2D` вместо зелёного
- **PhotoUploader**: убран `className` в пользу inline-стилей (конвенция проекта)
- **Backend**: каскадное удаление проектов при удалении пользователя, валидация пустого имени проекта, корректная обработка ошибок в репозитории
- **Производительность**: O(n²) конкатенация при base64-сериализации маски заменена на chunked-подход

### Фоторедактор стен v2: UX-полировка (Фаза 5)

- **Онбординг**: 3-шаговый тур (маска → дизайн → размещение) при первом посещении, с точечными индикаторами
- **До / После**: кнопка «До / После» открывает модальное окно (900px) с интерактивным слайдером сравнения; touch-поддержка на мобильных
- **Skeleton loading**: карточки дизайнов показывают скелетон до загрузки изображений, плавное появление через opacity-transition
- **Fullscreen**: кнопка полноэкранного режима для canvas-контейнера
- **Empty state**: информативная заглушка при отсутствии размещённых панелей
- **Кнопка «Примерить на фото»**: добавлена в конструктор стен, переход в фоторедактор с предвыбранным дизайном

### Фоторедактор стен v2: бэкенд и персистенция (Фаза 4)

- **CRUD API**: 5 эндпоинтов для проектов визуализации (`POST/GET/PUT/DELETE /api/visualizer/projects`)
- **DDD-архитектура**: entity `VisualizationProject`, value objects, repository (SQL + in-memory), 5 use cases с проверкой ownership
- **ORM-модель**: таблица `visualization_projects` с JSON-полями для панелей и перспективных углов
- **Zustand persist**: автоматическое сохранение состояния в localStorage с кастомной сериализацией Uint8Array ↔ base64
- **API-клиент**: полный CRUD для работы с бэкендом (сохранение/загрузка/удаление проектов)
- **Тесты**: 30 backend-тестов (domain + application + API), все frontend-тесты обновлены

### Фоторедактор стен v2: перспектива и калибровка (Фаза 3)

- **Калибровка масштаба**: пользователь указывает два конца известного объекта (дверь, розетка, окно) → автоматический расчёт масштаба
- **Перспективная трансформация**: 4 перетаскиваемых угловых маркера → панели деформируются под перспективу стены (homography math, без внешних зависимостей)
- **Адаптивная яркость**: яркость панелей подстраивается под освещение стены на фото (ITU-R BT.601)

### Фоторедактор стен v2: миграция на react-konva (Фаза 2)

- **Декларативный canvas**: замена 526 строк ручного Canvas API на react-konva — drag & drop панелей, hover, select из коробки
- **Маска на Konva**: рисование кистью/ластиком через offscreen canvas + Konva Image, undo (20 шагов)
- **Zoom & Pan**: скролл для масштабирования (0.25–4x), перетаскивание stage, pinch-to-zoom на тач-устройствах
- **Design System**: все компоненты (MaskToolbar, PlacementControls, PanelPicker, CostSummary) стилизованы по брендбуку

### Фоторедактор стен v2: ML-сегментация (Фаза 1)

- **Распознавание стен в браузере**: SegFormer-B0 через `@huggingface/transformers`, WASM/WebGPU, 150 классов ADE20K
- **Автоматическая маска**: загрузка фото → ML определяет стену и препятствия (двери, окна, мебель) → маска для размещения панелей
- **Прогресс загрузки модели**: статусы «Загружаем модель» → «Распознаём стену» → «Готово» с прогресс-баром
- **Graceful fallback**: при ошибке ML — переключение на ручную маску с сообщением «Отметьте стену кистью»
- **Нормализация маски**: автоматический ресайз выходной маски модели (512×512) до размера исходного фото

## 07.04.2026

### Конструктор стен: редизайн нижней части и мобильная вёрстка

- **Блок стоимости перенесён** из левой панели под визуализацию стены — логичнее в контексте рабочего процесса
- **Компактный горизонтальный layout стоимости**: статистика (панели, покрытие, стена) + цены (базовые, накладки) в CSS Grid-сетке слева, «Итого» и «В корзину» справа
- **Баннер подписки**: яркий полноширинный блок с зелёным градиентом, CTA-кнопкой, анимацией появления; для подписчиков — компактная информационная полоска
- **Размещённые панели (0 шт)**: блок легенды всегда отображается с placeholder «Добавьте панель», устраняя скачок интерфейса при добавлении первой панели
- **Кнопка «Очистить»** перенесена к «Заполнить» (логичная группировка), оставлена только иконка с tooltip
- **Свитчер размеров панели** растянут на полную ширину карточки
- **Мобильная адаптация конструктора**: CSS Grid дочерние элементы с `min-width: 0`, карточки с `overflow: hidden` и уменьшенным padding, статистика 2 колонки → 1 колонка на маленьких экранах, кнопки действий с `flex-wrap`
- **Исправлен горизонтальный скролл** на мобилке: баннер подписки ограничен `max-width: calc(100% - 24px)`, корневой контейнер с `overflowX: hidden`
- **Цена подписки обновлена**: от 7 000 ₽/мес (было 4 900 ₽/мес)

### Конструктор стен: доработки UX

- **Перетаскивание сетки**: в режиме «Интерьер» сетку можно зажать и передвинуть, чтобы точно совместить её со стеной на фото (работает и на мобиле)
- **Фото интерьера фиксировано**: при изменении размеров стены (количества ячеек) фон интерьера больше не масштабируется — меняется только сетка
- **Оттенки панелей**: цветовая тонировка стала заметно отличаться между оттенками; превью дизайна теперь тоже показывает выбранный оттенок
- **Крестик удаления**: появляется только при наведении на плитку, а не отображается постоянно
- **Исправлено ложное предупреждение**: сообщение «Невозможно разместить панель здесь» больше не появляется при перетаскивании панели на новое место

Модель подписки полностью переработана — вместо лимита на количество накладок теперь используется лимит по площади (м²/мес), как было заложено в ТЗ.

**Новые тарифы:**
- Стартовый: 15 м² — 7 000 ₽/мес
- Популярный: 30 м² — 12 000 ₽/мес
- Бизнес: безлимитная площадь — 18 000 ₽/мес

Обновлены: страница тарифов, модальное окно подписки, раздел подписки в личном кабинете, конструктор, API-эндпоинты, доменная модель, БД-миграция. Добавлена миграция localStorage для плавного перехода пользователей со старой версии.

## До 07.04.2026

### MVP — запуск продукта

Создание Wonder Wow Wall с нуля: B2C интернет-магазин магнитных стеновых панелей.

- **Каталог**: карточки дизайнов с фото, рейтингом, ценами, бейджами
- **Страница товара**: галерея, описание, характеристики, кнопка «В корзину»
- **Конструктор стен**: grid-система с привязкой к сетке, выбор размеров панелей и дизайнов, калькулятор стоимости
- **Подписочная модель**: 3 тарифа, модальное окно оформления, скидка для подписчиков
- **Корзина и оформление заказа**: многошаговый checkout, выбор доставки и оплаты
- **Авторизация**: регистрация, вход, JWT-токены
- **Личный кабинет**: профиль, заказы, избранное, адреса
- **Фоторедактор стен**: загрузка фото интерьера, выделение стены (кисть/ластик), размещение панелей, автозаполнение, калькулятор стоимости
- **Backend API**: FastAPI, DDD-архитектура (домены, use cases, репозитории)
- **Интеграция**: фронтенд подключён к бэкенду через API-хуки (React Query)
