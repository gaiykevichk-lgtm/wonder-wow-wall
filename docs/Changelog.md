## 07.04.2026

### Подписка: переход на тарификацию по площади

Модель подписки полностью переработана — вместо лимита на количество накладок теперь используется лимит по площади (м²/мес), как было заложено в ТЗ.

**Новые тарифы:**
- Стартовый: 15 м² — 7 000 ₽/мес
- Популярный: 30 м² — 12 000 ₽/мес
- Бизнес: безлимитная площадь — 18 000 ₽/мес

Обновлены: страница тарифов, модальное окно подписки, раздел подписки в личном кабинете, конструктор, API-эндпоинты, доменная модель, БД-миграция. Добавлена миграция localStorage для плавного перехода пользователей со старой версии.

### Мобильная адаптация и touch-поддержка

Весь интерфейс адаптирован под планшеты и телефоны:

- Адаптивная вёрстка на всех страницах (breakpoints: 1024px / 768px / 480px)
- Личный кабинет: боковое меню превращается в горизонтальные табы
- Фоторедактор стен: pinch-to-zoom, рисование пальцем (кисть/ластик), перемещение одним и двумя пальцами
- Плавающая кнопка поддержки на всех страницах (email, телефон, Telegram, часы работы)

### SEO и мета-теги

- Уникальные title и description на 17 страницах
- Open Graph и Twitter Cards для предпросмотра ссылок в соцсетях и мессенджерах
- Favicon и apple-touch-icon

### Docker-стек и CI/CD

- Docker Compose: nginx (reverse proxy) + frontend + backend + PostgreSQL + Redis
- Frontend собирается в multi-stage Docker-образ (Node → Nginx)
- Nginx: SPA fallback, gzip, кэш статики, security headers
- GitHub Actions: автоматический прогон линтера, typecheck, тестов и Docker build

---

### Безопасность бэкенда

- CORS: разрешён только конкретный origin фронтенда (не `*`)
- Rate limiting: login 5/min, register 3/min, forgot-password 3/min, глобально 60/min
- Защита от запуска с дефолтным JWT-секретом в production
- Security-заголовки: X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy

### Личный кабинет и авторизация

- Поиск в шапке сайта: иконка → разворачивающееся поле → переход в каталог с результатами
- Избранное в шапке с бейджем количества
- Восстановление пароля: ввод email → код (6 цифр, действует 15 мин) → новый пароль
- Кнопки «Войти через Google» и «Войти через VK» (placeholder, скоро)
- Раздел «Уведомления» в ЛК: переключатели email-рассылок
- Кнопка «Повторить заказ» — копирует товары из прошлого заказа в корзину

---

### Оформление заказа: дата монтажа, СБП, быстрая примерка

- Выбор даты и времени монтажа при оформлении (только будущие даты, рабочие часы 9:00–20:00)
- Оплата через СБП (Система Быстрых Платежей) — 4-й способ оплаты
- Кнопки «Примерить на фото» и «Примерить в конструкторе» на страницах каталога и товара
- Переход из карточки товара сразу в конструктор или фоторедактор с предвыбранным дизайном

### Подключение PostgreSQL

Переход с хранения данных в памяти на полноценную базу данных:

- Схема БД: 9 таблиц с внешними ключами и каскадным удалением
- 7 репозиториев для работы с БД через SQLAlchemy (async)
- Скрипт заполнения начальными данными (12 дизайнов, 6 категорий)
- Режим in-memory сохранён как fallback для тестов и разработки без БД

## До 07.04.2026

### MVP — запуск продукта

Создание Wonder Wow Wall с нуля: B2C интернет-магазин магнитных стеновых панелей.

- **Каталог**: карточки дизайнов с фото, рейтингом, ценами, бейджами
- **Страница товара**: галерея, описание, характеристики, кнопка «В корзину»
- **Конструктор стен**: grid-система с привязкой к сетке, выбор размеров панелей и дизайнов, калькулятор стоимости
- **Подписочная модель**: 3 тарифа, модальное окно оформления, скидка для подписчиков
- **Корзина и оформление заказа**: многошаговый checkout, выбор доставки и оплаты
- **Авторизация**: регистрация, вход, JWT-токены
- **Личный кабинет**: профиль, заказы, избранное, адреса
- **Фоторедактор стен**: загрузка фото интерьера, выделение стены (кисть/ластик), размещение панелей, автозаполнение, калькулятор стоимости
- **Backend API**: FastAPI, DDD-архитектура (домены, use cases, репозитории)
- **Интеграция**: фронтенд подключён к бэкенду через API-хуки (React Query)
