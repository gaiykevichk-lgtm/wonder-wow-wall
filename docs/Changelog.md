### Фоторедактор стен: устранение дефектов после тестирования

Проведено ручное тестирование фоторедактора. Выявлено и исправлено 10 дефектов:

- **Текстуры панелей** теперь корректно отображаются на canvas — ранее панели рисовались сплошным цветом без наложения дизайна
- **Точное размещение панелей**: клик по ячейке теперь ставит панель именно туда, куда указал пользователь, без смещения
- **Мгновенное рисование маски**: кисть и ластик рисуют в реальном времени — убрана задержка в 2–3 секунды между движением мыши и появлением мазка
- **Калибровка масштаба** снова работает корректно — восстановлена связь между кликом по canvas и установкой точек калибровки
- **Сравнение «До / После»**: «До» теперь слева, «После» справа (было перепутано)
- **Полноэкранный режим** работает в браузерах с ограничениями iframe — добавлен CSS-режим как запасной вариант
- **Убран красный круг**, который ошибочно отображался по центру canvas при редактировании маски
- **Автозаполнение стены** («Заполнить стену») снова работает — устранена проблема с инициализацией выбранного дизайна при загрузке страницы
- Добавлены информативные уведомления при автозаполнении: причина, если панели не удалось разместить

### Фоторедактор стен v2

Полная переработка фоторедактора стен — от загрузки фото до оформления заказа. Реализовано в 5 фазах.

**ML-распознавание стен:**
- Автоматическое определение стен и препятствий (двери, окна, мебель) на загруженном фото — распознавание работает прямо в браузере, без отправки данных на сервер
- Прогресс-бар загрузки модели при первом использовании (~15 МБ, затем кэшируется)
- При ошибке распознавания — автоматический переход на ручное выделение стены кистью

**Интерактивный canvas (react-konva):**
- Панели можно перетаскивать мышью и размещать на стене
- Рисование маски кистью/ластиком с поддержкой отмены (до 20 шагов)
- Масштабирование колёсиком (0.25–4x), перемещение canvas, pinch-to-zoom на мобильных
- Подсветка ячейки при наведении, выделение и удаление панелей кликом

**Перспектива и калибровка:**
- 4 угловых маркера для подгонки панелей под перспективу стены на фото
- Калибровка масштаба по известному объекту (дверь, розетка, окно)
- Автоматическая подстройка яркости панелей под освещение на фото

**Сохранение проектов:**
- Проекты визуализации сохраняются на сервере (фото, маска, панели, настройки перспективы)
- Автоматическое сохранение состояния в браузере при перезагрузке страницы
- API для создания, загрузки, обновления и удаления проектов

**UX-полировка:**
- Онбординг-тур из 3 шагов при первом посещении
- Сравнение «До / После» — интерактивный слайдер в модальном окне
- Скелетоны загрузки для карточек дизайнов
- Полноэкранный режим для canvas
- Информативная заглушка при отсутствии размещённых панелей
- Кнопка «Примерить на фото» в конструкторе стен

## 07.04.2026

### Конструктор стен: редизайн нижней части и мобильная вёрстка

- **Блок стоимости перенесён** из левой панели под визуализацию стены — логичнее в контексте рабочего процесса
- **Компактный горизонтальный layout стоимости**: статистика (панели, покрытие, стена) + цены (базовые, накладки) в CSS Grid-сетке слева, «Итого» и «В корзину» справа
- **Баннер подписки**: яркий полноширинный блок с зелёным градиентом, CTA-кнопкой, анимацией появления; для подписчиков — компактная информационная полоска
- **Размещённые панели (0 шт)**: блок легенды всегда отображается с placeholder «Добавьте панель», устраняя скачок интерфейса при добавлении первой панели
- **Кнопка «Очистить»** перенесена к «Заполнить» (логичная группировка), оставлена только иконка с tooltip
- **Свитчер размеров панели** растянут на полную ширину карточки
- **Мобильная адаптация конструктора**: CSS Grid дочерние элементы с `min-width: 0`, карточки с `overflow: hidden` и уменьшенным padding, статистика 2 колонки → 1 колонка на маленьких экранах, кнопки действий с `flex-wrap`
- **Исправлен горизонтальный скролл** на мобилке: баннер подписки ограничен `max-width: calc(100% - 24px)`, корневой контейнер с `overflowX: hidden`
- **Цена подписки обновлена**: от 7 000 ₽/мес (было 4 900 ₽/мес)

### Конструктор стен: доработки UX

- **Перетаскивание сетки**: в режиме «Интерьер» сетку можно зажать и передвинуть, чтобы точно совместить её со стеной на фото (работает и на мобиле)
- **Фото интерьера фиксировано**: при изменении размеров стены (количества ячеек) фон интерьера больше не масштабируется — меняется только сетка
- **Оттенки панелей**: цветовая тонировка стала заметно отличаться между оттенками; превью дизайна теперь тоже показывает выбранный оттенок
- **Крестик удаления**: появляется только при наведении на плитку, а не отображается постоянно
- **Исправлено ложное предупреждение**: сообщение «Невозможно разместить панель здесь» больше не появляется при перетаскивании панели на новое место

Обновлены: страница тарифов, модальное окно подписки, раздел подписки в личном кабинете, конструктор, API-эндпоинты, доменная модель, БД-миграция. Добавлена миграция localStorage для плавного перехода пользователей со старой версии.

### Docker-стек и CI/CD

- Docker Compose: nginx (reverse proxy) + frontend + backend + PostgreSQL + Redis
- Frontend собирается в multi-stage Docker-образ (Node → Nginx)
- Nginx: SPA fallback, gzip, кэш статики, security headers
- GitHub Actions: автоматический прогон линтера, typecheck, тестов и Docker build

### Безопасность бэкенда

- CORS: разрешён только конкретный origin фронтенда (не `*`)
- Rate limiting: login 5/min, register 3/min, forgot-password 3/min, глобально 60/min
- Защита от запуска с дефолтным JWT-секретом в production
- Security-заголовки: X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy

## До 07.04.2026

### MVP — запуск продукта

Создание Wonder Wow Wall с нуля: B2C интернет-магазин магнитных стеновых панелей.

- **Каталог**: карточки дизайнов с фото, рейтингом, ценами, бейджами
- **Страница товара**: галерея, описание, характеристики, кнопка «В корзину»
- **Конструктор стен**: grid-система с привязкой к сетке, выбор размеров панелей и дизайнов, калькулятор стоимости
- **Подписочная модель**: 3 тарифа, модальное окно оформления, скидка для подписчиков
- **Корзина и оформление заказа**: многошаговый checkout, выбор доставки и оплаты
- **Авторизация**: регистрация, вход, JWT-токены
- **Личный кабинет**: профиль, заказы, избранное, адреса
- **Фоторедактор стен**: загрузка фото интерьера, выделение стены (кисть/ластик), размещение панелей, автозаполнение, калькулятор стоимости
- **Backend API**: FastAPI, DDD-архитектура (домены, use cases, репозитории)
- **Интеграция**: фронтенд подключён к бэкенду через API-хуки (React Query)
