# Навигация к карточке базовой формы

## Цель

При переходе из длинного списка `/catalog` на `/catalog/:panelId` карточка товара должна открываться с верхней границы страницы, включая мобильные браузеры.

## Реализация

Компонент `src/shared/ui/ScrollToTop.tsx` отслеживает изменение `location.pathname` и синхронно сбрасывает прокрутку документа в `(0, 0)` через `useLayoutEffect`. Компонент подключён в `ShopLayout`, поэтому правило применяется ко всем публичным маршрутам магазина.

Изменение только query-параметров не сбрасывает позицию: фильтры каталога продолжают работать без неожиданного прыжка наверх.

## Проверка

- unit-тест перехода `/catalog` → `/catalog/:panelId`;
- unit-тест сохранения позиции при изменении query-параметров;
- TypeScript и production build;
- мобильный пользовательский сценарий в preview и production.
