# Фильтр размеров в каталоге админ-панели

Цель: во вкладке «Варианты панелей» добавить фильтр размера, независимый от селектора редактирования размера базовой формы в строке.

Стек: существующий React 19 / TypeScript / Vite 8 / Ant Design 6. Реализация в `src/domains/admin/ui/AdminPanelsPage.tsx`: локальный фильтр по `width_mm` и `height_mm` панели из списка назначений; варианты 30×30, 60×60 и 30×60 см берутся из `PANEL_SIZES`. Фильтр совместим с выбором формы и текстуры, сбрасывает страницу таблицы на первую, очищается через `allowClear`. API и схема хранения не меняются.

Проверка: `npm run test -- src/domains/admin/__tests__/AdminPanelsPage.test.tsx`; `npm run build`. Запуск: `npm run dev -- --host 0.0.0.0 --port <свободный порт>`. Для локального API Vite проксирует `/api` к `VITE_BACKEND_URL` (по умолчанию локальный порт 8081). Секретов нет.

Фильтр «Базовая форма» объединяет SKU размеров по family slug, удаляя только известный суффикс размеров (`300x300`, `300x600`, `600x600`); это надёжнее дедупликации по подписи и не склеивает самостоятельные формы с одинаковым именем. При выборе формы показываются её строки всех размеров. Размер остаётся отдельным независимым фильтром. Регрессионный тест моделирует одну форму «КРУГ» в размерах 30×30 и 60×60.

Статус: изменение локального исходного кода; опубликованная версия не обновлялась.
