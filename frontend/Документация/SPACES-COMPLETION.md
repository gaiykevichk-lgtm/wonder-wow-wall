# Доработка Spaces после аудита
Цель: реальные сцены и исполнения без подмены фото и приблизительного выбора.
Стек существующий: React/Vite/TypeScript. Запуск npm run dev; тесты npm test.
Изменения: контракт проверенных рендеров (сцена/панель/фактура/режим), точная
привязка к товару, сброс фильтров, стоимость просмотра, контроль медиа.
Блокеры: локальный API каталога отвечает 502; текущие 14 записей содержат
побайтовые дубликаты фото, нет связанных рендеров и точных ID исполнений.
Не генерировать и не выдавать вымышленные медиа за согласованные.
Публикация не выполняется до заполнения контента и приёмки.
