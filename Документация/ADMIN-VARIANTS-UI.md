## 26.09.2026 — единое сохранение фото нескольких исполнений

В модальном редакторе «Фото в дизайне» и «Рекомендации» черновики галерей хранятся по ID исполнения на время открытия модалки. При переключении на другое исполнение загруженные, удалённые и переупорядоченные фото предыдущего исполнения остаются в черновике. Одно нажатие «Сохранить» последовательно отправляет изменения каждого затронутого исполнения; при ошибке оставшиеся черновики не очищаются, модалка остаётся открытой для повтора. «Отмена» сбрасывает черновики. Переключение блокируется, пока загрузка не закончена. Это несколько API PATCH по нажатию одной кнопки, не атомарная общая серверная транзакция.

## 26.09.2026 — добавление нескольких исполнений в одной строке

В таблице `/admin/catalog` кнопка добавления исполнения в ячейке показывалась только при пустом списке `executions`. Для непустой пары «панель + текстура» доступен был лишь общий плюс в заголовке без контекста строки. Теперь плюс в ячейке доступен всегда и передаёт идентификаторы именно этой панели и текстуры в существующий редактор создания; он располагается после миниатюр, перед корзиной. Backend уже поддерживает несколько записей на пару и сам выставляет следующий `sort_order`, миграция не требуется. Добавлен компонентный тест для непустой строки.

Проверки: целевой компонентный тест 1/1, production build frontend успешен. Полный файл тестов не завершился за 120 секунд в текущем окружении. Публикация на wonderwowwall.ru и авторизованный сценарий создания в production этим изменением не подтверждены.
