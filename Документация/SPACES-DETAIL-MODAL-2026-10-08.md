# Единое окно пространства

Запрос: клик карточки /spaces открывает модалку с загруженными фотографиями и описанием слева, существующим CalculatorSidebar справа. На мобильном — вертикальная компоновка. Используем React/Vite и существующие Ant Design Modal, калькулятор, каталог и корзину; отдельный калькулятор не создаём.

Изменения: публичный SpaceCard получает images из image_paths (первое фото — обложка), новый SpaceDetailModal связывает семейство панели/фактуру с каталогом и передаёт контекст существующему калькулятору. CalculatorSidebar получает необязательный embedded режим без fixed/overlay. Не изменять галереи или пользовательские данные.

Запуск frontend: npm run dev -- --host 0.0.0.0 --port 5175. Для проверки живых read API VITE_BACKEND_URL=https://wonderwowwall.ru. Секреты не требуются. Статус: реализация и проверки в процессе; production пока не опубликован.
