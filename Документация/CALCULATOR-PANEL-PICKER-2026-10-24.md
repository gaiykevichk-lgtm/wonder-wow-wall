# Выбор панели из карточки калькулятора — 2026-10-24

## Brief
В правой панели «Рассчитать проект» выбранная панель должна быть интерактивной: по нажатию открывается окно выбора панелей. Каждая строка выбора показывает миниатюру слева и название справа.

## Реализация
- Стек проекта сохранён: React 19, TypeScript, Vite.
- Изменяются `frontend/src/domains/catalog/ui/CalculatorSidebar.tsx` и `CatalogPanelPage.tsx`; добавляется тест сценария в `CalculatorSidebar.test.tsx`.
- Попап содержит список панелей, доступный из каталога. При выборе выполняется переход к карточке соответствующей панели, чтобы контекст калькулятора (варианты/цены) оставался связан с выбранным товаром.

## Проверки
Vitest, TypeScript, production build и визуальная проверка preview после реализации.

## Статус
Реализация выполнена; публикация production не запрошена в этом сообщении.
