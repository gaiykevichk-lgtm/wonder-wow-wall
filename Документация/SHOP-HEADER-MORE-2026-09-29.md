# Навигация «Ещё» в шапке

Запрос: при нажатии на «Ещё» на опубликованном сайте открывалась главная страница вместо меню.

Причина: триггер был ссылкой на `/showrooms`, но в приложении нет такого маршрута; catch-all роутера показывал главную страницу. Список появлялся только при наведении.

Решение: триггер «Ещё» — кнопка с `aria-expanded` и `aria-haspopup`, открывающая существующий `Dropdown` нажатием и наведением, без навигации. Ссылки внутри списка сохранены без изменений.

Проверки: компонентный тест проверяет клик с `/configurator`, открытое состояние меню и неизменный путь; TypeScript и сборка frontend прошли. На VM сохранён бэкап прежнего HTML и JS в `/opt/app/deploy-backups/header-more-20260929T165133Z/`, опубликован точечно изменённый entry JS (другие незавершённые изменения не переносились). Публичные HTML и новый JS отвечают 200, проверены синтаксис JS и отсутствие старой ссылки в опубликованном триггере. Публичный скриншот показывает только индикатор загрузки, поэтому поведение клика на production визуально/интерактивно не подтверждено. Не выдавать HTTP и тест за полную проверку пользовательского сценария.
