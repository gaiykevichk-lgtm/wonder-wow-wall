Резервная копия исходного HTML: `/opt/app/deploy-backups/home-mobile-spacing-20260927/index.html`. ## Две строки на мобильном (27.09.2026, вторая правка)

По уточнению брига: на мобильном заголовок карточки «Цифровой интеллект» должен оставаться в 2 строки. Удалено мобильное правило `.home-service-card-title br { display: none; }`, пробел `{" "}` перенесён до `<br />`, чтобы вторая строка не получала ведущий отступ, а `textContent` сохранял пробел (регрессионный тест без изменений). Стили `.home-service-*` перенесены из общего `<style>` страницы в сам компонент `ServiceBannerSection`, чтобы правила всегда жили вместе с разметкой. Проверено: изолированный рендер секции в iframe 390px (две строки, без наложения), `vitest run src/domains/content` — 71 тест зелёный.
