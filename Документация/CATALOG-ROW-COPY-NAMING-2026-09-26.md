# Копирование строк каталога: имя и слаг

Задача: копия строки «Варианты панелей» не должна показывать «(копия)» в названии базовой формы. Название копируется без изменения для строк с фактурой и без неё. Наименование базовой формы остаётся общим для исходной и скопированной строки.

Уточнение требований: `panels.slug` — повторяемая метка общей базовой формы; уникален только `panels.id`. Копирование строки создаёт отдельную запись панели с новым ID, тем же именем и тем же слагом. `GET /catalog/:panelId` адресует конкретную панель по ID. Миграция 032 снимает ограничение `uq_panels_slug` и сохраняет обычный индекс по слагу. Данные исходной панели и её медиа не меняются. Старые копии с `-copy` остаются без массового переписывания данных.

В отображении новых копий сохраняется позиция непосредственно перед исходной строкой, если это соседние новые формы; для ранее созданных записей с `-copy` сохраняется прежняя сортировка. Локальные выборочные backend-тесты проверяют одинаковый слаг и разные ID, а также idempotent size wizard. На production: резервная копия БД и backend-файлов создана; фактическая схема уже имела `sort_order`/индекс ревизии 031 при записи `030` в `alembic_version`, поэтому она помечена как 031 без повторного ранжирования строк. В транзакции снято только ограничение `uq_panels_slug`, ревизия обновлена до 032. Пробное создание второго panel с тем же слагом на реальной БД и откат транзакции прошло. Не выполнять автоматический `alembic upgrade 031` поверх текущих данных. Авторизованное копирование через UI в production отдельно не подтверждено.
