# Мобильная адаптация админ-панели

Исходный запрос: на узком экране шапка с email и выходом переполняет viewport, вкладки каталога и фильтры занимают лишнюю ширину, таблица вариантов панелей обрезается. Скриншот предоставлен пользователем.

Подход: в пределах 768 px общая админская оболочка ограничена шириной viewport; шапка показывает кнопку меню, краткий заголовок и иконки перехода на сайт/выход (с доступными названиями). Навигация остаётся в Drawer. Каталог сохраняет горизонтальную прокрутку вкладок, фильтры вариантов панелей/форм/исполнений переносятся в одну колонку. Большие таблицы прокручиваются горизонтально внутри своей области, без горизонтальной прокрутки всей страницы. Текущие данные, CRUD и десктопные раскладки не меняются.

Файлы: `frontend/src/domains/admin/ui/adminResponsive.css`, `AdminLayout.tsx`, `AdminCatalogPage.tsx`, `AdminPanelsPage.tsx`, `AdminUploadPage.tsx`, `AdminExecutionsPage.tsx`, `AdminTexturesPage.tsx`, тест оболочки `frontend/src/domains/admin/__tests__/AdminLayout.test.tsx`.

Проверка исходного варианта: TypeScript, 61 компонентный тест (оболочка, варианты, формы) и сборка frontend прошли. Локальный Preview не показал страницу приложения. Визуальная проверка мобильного экрана и авторизованная проверка админки не завершены.

Публикация 29.09.2026: пока в общей рабочей папке были незавершённые параллельные правки frontend/backend, на существующий прод `wonderwowwall.ru` не отправлялась новая сборка JS. Вместо этого опубликован изолированный совместимый с текущими продовыми DOM-классами мобильный stylesheet `frontend/public/admin-mobile-prod.css`: адаптация шапки, вкладок, фильтров и прокрутка таблиц. Текущий продовый `index.html` изменён лишь ссылкой на этот файл, без замены существующих JS/CSS-чанков. Старый `index.html` сохранён на VM в `/opt/app/deploy-backups/pre-admin-mobile-20260929-2230/`; для отката также следует удалить или отключить подключение stylesheet. После изменения основной домен вернул 200 для маршрута, stylesheet и `/api/health`; хеш публичного CSS совпал с локальным. Публичный снимок показал экран входа, поэтому работу адаптивной таблицы в авторизованной сессии эта проверка не доказывает. Изменения TypeScript из локальной рабочей папки этим релизом не публиковались; перед будущей полной сборкой их нужно согласовать с параллельными правками.
