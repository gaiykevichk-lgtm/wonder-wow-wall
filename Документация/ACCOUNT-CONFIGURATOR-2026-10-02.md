# Замена конструктора в личном кабинете
Пользователь подтвердил замену старого редактора стены в личном кабинете существующим /configurator. Меню ведёт непосредственно туда, /account/constructor перенаправляет с replace. Создание новых проектов ведёт в конфигуратор. Сохранённые legacy-проекты и их данные не удаляются; существующий конфигуратор не импортирует их раскладку, поэтому переход не выдаётся за загрузку legacy-проекта. Старые ссылки открытия также ведут через redirect. Публичный /constructor вне кабинета не изменяется в рамках подтверждённого scope. Админка, backend, БД, миграции не меняются.
Стек и запуск прежние: React/TypeScript/Vite, npm run dev/build/test в frontend. Новых env нет. Изменяемые файлы: shared/router.tsx, AccountLayout.tsx, ProjectsSection.tsx. Статус: реализация и проверка.
Проверка: TypeScript и Vite build прошли, AccountLayout 5/5 тестов passed. Изменения опубликованы с backup index.html /opt/app/frontend/backups/account-configurator-20261002. В авторизованном production-browser прямой /account/constructor перешёл в /configurator; пункт «Конфигуратор» в кабинете также проверен кликом, открывает заголовок «Загрузите фото вашей стены». Backend health ok. Legacy проекты не удалены; их открытие больше не загружает старую раскладку. Публичный /constructor пока сохранён отдельно. Полный сценарий генерации/сохранения конфигуратора не тестировался и не менялся.
