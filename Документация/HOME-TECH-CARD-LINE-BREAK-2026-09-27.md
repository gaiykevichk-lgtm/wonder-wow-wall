# Перенос слова «современных» в карточке технологий

27.09.2026. В карточке «Универсальная платформа монтажа.» описание «Адаптирована для большинства современных поверхностей.» переносилось так, что на второй строке оставалось одинокое слово «поверхностей.».

Исправление: в `techPoints` (`frontend/src/domains/content/ui/HomePage.tsx`) добавлен явный `\n`: «Адаптирована для большинства\nсовременных поверхностей.». Рендер описаний уже поддерживает `pre-line` для строк с `\n` (как в карточке «Безграничность фактур.»).

Проверено: изолированный рендер `TechSection` в iframe 1280px — две ровные строки; `vitest run src/domains/content` — 72 теста зелёные. Правка появится на проде после пересборки и публикации фронтенда.
