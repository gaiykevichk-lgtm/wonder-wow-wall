# Удаление селектора «Вариант материала» из модалки пространства

## Запрос
Убрать нижнее поле «Вариант материала» из модального окна страницы `/spaces`; оставить выбор варианта через галерею и верхние контроли калькулятора.

## Реализация
Из `frontend/src/domains/content/ui/SpaceDetailModal.tsx` удалён JSX-селектор и неиспользуемые `Select`/`configurationOptions`. Тест `frontend/src/domains/content/ui/__tests__/SpaceDetailModal.test.tsx` проверяет отсутствие подписи и поля.

## Проверки
Тест модалки прошёл (1/1), `tsc --noEmit` прошёл, `npm run build` прошёл. Изменение ещё не опубликовано.
