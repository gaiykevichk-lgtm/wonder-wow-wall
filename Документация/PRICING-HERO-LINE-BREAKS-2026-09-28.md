# Переносы во вступлении страницы подписки

Запрос: на `/pricing` вывести вступительный абзац тремя фразовыми строками: после первого предложения и после запятой перед «который может меняться вместе с Вами». На узких экранах каждая фразовая строка может дополнительно переноситься по ширине экрана — это не запрет на естественную адаптивную вёрстку.

Исходник: `frontend/src/domains/subscription/ui/PricingPage.tsx`. Адресный тест: `frontend/src/domains/subscription/ui/__tests__/PricingHeroLineBreaks.test.tsx`.

На действующей версии сайта сохранена прежняя страница `/opt/app/deploy-backups/pricing-hero-three-lines-20260928/index.html` и внесена изолированная правка абзаца в `index.html` (без публикации посторонних незавершённых изменений репозитория). После будущей согласованной сборки фронтенда временную правку в HTML следует удалить, проверив, что сборка содержит два `<br>` в этом абзаце.

Проверки: адресный тест прошёл, TypeScript прошёл; HTML на публичном `/pricing` содержит адресную правку и возвращает HTTP 200. Сервис снимков не подтвердил отображение самого абзаца и мобильную геометрию: визуальную проверку не считать завершённой.
