Для коробки 1,08 м²: 10,8 × 1,1 / 1,08 = 11 точно. В коде float + ceil, поэтому число чуть больше 11 округляется до 12. Нужен точный денежный/площадной расчёт и тест границы.

Дополнительно: API вернул 2400 ₽ за панель 300×300 без design_id, тогда как наблюдавшаяся PDP после выбора дерева показывала 2090 ₽. Это подтверждает отсутствие единой цены по выбранному варианту; не означает, что 2400 — утверждённая цена.

Повторно проверены сохранённые результаты четырёх целевых прогонов: 46 + 31 + 24 + 41 = 142 успешных теста. Дополнительно выполнен ограниченный прогон корзины, авторизации, кабинета, цен конструктора и выделения зоны конфигуратора: **9 файлов, 65 тестов — 62 успешно, 3 с ошибкой; 7 файлов прошли, 2 не прошли**.

### Причины трёх падений

1. Два теста `confirmedExecutions.test.ts` читают живой production API и требуют товар «ДЕМО 2» с определённым количеством исполнений кожи/текстиля. Нужных записей нет. Падение происходит до проверки корзины и не доказывает поломку разделения её строк. Такие проверки должны использовать изолированные фикстуры, а не требовать заполнения пользовательского каталога тестовыми товарами.
2. `confirmedMetalExecution.test.ts` читает исходник компонента, удаляет часть TypeScript-аннотаций строковыми заменами и запускает результат через `new Function`. Выполнение падает с `Unexpected token ':'` до проверки поведения корзины. Это дефект способа тестирования, не подтверждённая ошибка production UI.

Ни тесты, ни каталог для получения зелёного результата не изменялись. Лог дополнительного прогона сохранён рядом с предыдущими в `Документация/audit-2026-09-24/www-audit-continuation.log`.

### Повторно сверенные критичные выводы

- `ShopHeader.tsx` формирует `/catalog?search=…`, `CatalogPage.tsx` инициализирует поиск из `q`: несовпадение подтверждено непосредственно кодом.
- `ConfiguratorAiPage.tsx`: успешная склейка вызывает только уведомление «Панорама склеена», не передачу изображения в новую сессию.
- `orders.py` передаёт `unit_price` из входной модели в `CreateOrder`; use-case валидирует variant_id, принадлежность панели и фактуры, но затем сохраняет переданное `unit_price`. Независимого серверного определения цены в этом пути не обнаружено. Эксплуатация на production и создание заказа не выполнялись.
- Оборванное сообщение о расчёте следует читать как **11 коробок**, не 1: `10,8 × 1,1 / 1,08 = 11`. Ранее API возвращал 12 для размеров 300×300 и 300×600.
