# Строка базовой формы без текстуры — 26.09.2026

Причина: видимая строка без выбранной текстуры — виртуальная строка из базовой панели, а не catalog assignment. Операции над assignment по пустому `texture_id` к ней неприменимы.

Для такой строки переключатель меняет `panels.is_active` через существующий PATCH панели; выбор текстуры по-прежнему создаёт catalog assignment. Копирование вызывает новый `POST /api/admin/panels/{panel_id}/duplicate`, который копирует свойства панели и активность с уникальным slug, но запрещает копировать панели с назначенной строкой каталога (для них используется прежний endpoint копирования строки). Неактивные базовые формы без assignment остаются видимыми в админ-таблице для повторного включения. Фильтрация по активности админ-списка отключена для этой таблицы.

Проверки: backend unit-тесты 5/5; целевой компонентный тест для формы без фактуры; frontend type-check и build. Production: точечный серверный файл поверх текущего production; frontend — сборка от базы production `3a1d594` с исправлениями активности/копирования `84d4467` и новым действием. Снимок админ-экрана без авторизации недоступен: отдельной проверки авторизованного сценария на production не было.

Резервная копия на сервере: `/opt/app/deploy-backups/unassigned-row-20260926T140458Z`.

## Удаление строки без фактуры

В правой корзине «Вариантов панелей» для строки без назначенной фактуры теперь вызывается `DELETE /api/admin/panels/{panel_id}`, а не удаление catalog assignment с пустым `texture_id`. Для строки с фактурой остаётся прежний `DELETE /api/admin/panel-variant-rows` по паре panel+texture. Подтверждение явно предупреждает, что базовая панель будет удалена (и для последней строки с фактурой тоже). После успешного удаления обновляются panels, assignments и variants.

Проверены компонентный тест на удаление строки без фактуры, TypeScript и frontend build. Публикация на wonderwowwall.ru не подтверждена: восстановление SSH-доступа к VM вернуло ошибку сервиса. Авторизованный сценарий на production не проверен.
