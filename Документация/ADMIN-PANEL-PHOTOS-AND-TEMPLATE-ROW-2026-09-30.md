## Запрос

   уже добавленные к базовой форме; добавлять новые, удалять и изменять их.
2. Кнопка «добавить из ранее созданной базовой панели» — как пустая новая
   строка-шаблон: такая же, как остальные строки, только незаполненная.

## Реализация

### 1. Галерея фото базовой формы (компонент `PanelPhotosCell`)

В ячейке «Базовые формы» под селектором размера отображаются миниатюры
`panel.photo_paths` (до 2, fallback на `photo_path`). Для каждой миниатюры:

- клик по фото — открывает существующий drawer просмотра формы;
- кнопка «Заменить фото N» (иконка загрузки в углу) — выбор файла через
  скрытый `<input type="file">` внутри ячейки, загрузка через
  `uploadFile({ purpose: "PANEL_PHOTO" })` и `PATCH /admin/panels/{id}` с
  новым массивом `photo_paths` (элемент по индексу заменяется);
- кнопка «Удалить фото N» (крестик в углу) — Popconfirm, затем PATCH с
  массивом без этого фото. Пустой массив `[]` очищает галерею и primary-фото
  (серверный `sync_photos`).

Если фото меньше двух — плитка «Добавить фото формы» загружает файл и
дополняет галерею (`slice(0, 2)`). Один скрытый input на ячейку: слот
(`replaceIndex` или `add`) хранится в локальном состоянии `uploadSlot`;
`event.target.value` сбрасывается, чтобы повторный выбор того же файла тоже
срабатывал.

Заодно исправлен баг: иконка кнопки «Просмотр формы» брала `panel?.photo_path`
пропа страницы вместо `targetPanel.photo_path` строки.

### 2. Пустая строка-шаблон из существующей базовой панели

В шапке колонки «Базовые формы» рядом с «Добавить панель» появилась кнопка
«Добавить строку из базовой панели» (иконка FileAdd). Popover содержит
поисковый селектор базовых панелей, у которых уже есть хотя бы одна строка
каталога (панели без строк и так видны пустой строкой автоматически).

Выбор панели добавляет локальную draft-строку (`id: draft:<panelId>`) в начало
таблицы (state `draftRows: string[]`). Строка выглядит как остальные: панель с
фото и размером заполнена, фактура пустая («Выберите текстуру»), колонки
исполнений/дизайна/рекомендаций показывают «Сначала выберите фактуру»,
переключатель активности и копирование отключены.

- Выбор фактуры в draft-строке вызывает существующий
  `PATCH /admin/panel-variant-rows/texture` с пустым `current_texture_id`:
  backend создаёт catalog row (assignment) в той же транзакции — работает и
  для панели, у которой уже есть другие строки. После успеха draft
  снимается, списки обновляются.
- «Удалить строку» на draft-строке только убирает шаблон локально
  (`handleDeleteRow` имеет guard по префиксу `draft:`) и никогда не трогает
  базовую панель или назначения.

### 3. Тесты

Добавлены кейсы: показ миниатюр с действиями; удаление фото (PATCH с `[]`);
замена фото (мок `uploadFile` → PATCH заменённым массивом); добавление фото
(массив дополняется); добавление draft-строки через Popover; сохранение
строки-шаблона при выборе фактуры; удаление шаблона без вызова удаления
панели/назначения. Мок `../lib/uploadFile` вынесен в `vi.mock`.

Примечание по тестам: role-запросы по accessible name для нативной
кнопки-миниатюры в jsdom оказались патологически медленными (вычисление
accName по всему документу), поэтому проверки фото используют
`getByLabelText` (прямое совпадение aria-label).

## Нормализация колонки «Базовые формы» и постоянная пустая строка (12:00–12:30 UTC, 2026-09-30)

Запрос: привести колонку «Базовые формы» к виду остальных колонок (скриншот `pasted-1790767876826.png`: миниатюры с крошечными кнопками «заменить/удалить» на углах + селектор размера в ячейке); пустая строка-шаблон должна быть видна постоянно сверху таблицы, а не за кнопкой «Добавить строку из базовой панели».

### Решение (`frontend/src/domains/admin/ui/AdminPanelsPage.tsx`)

- **Ячейка «Базовые формы»** теперь устроена как остальные галерейные колонки: превью-кнопка с первым фото (`Просмотр формы`), название + карандаш, и под ними обычный `GalleryCell` (сетка 4×40px миниатюр + пунктирная плитка «Добавить фото формы»). Кнопки на углах миниатюр убраны из ячейки.
- **Действия с фото** (добавить/заменить/удалить фото N) перенесены в карточку просмотра `PanelPreviewDrawer`: там же скрытый `input[type=file]` (`Выбор файла фото формы`), загрузка через `uploadFile` + PATCH `photo_paths`.
- **Селектор размера убран из ячейки** — размер виден в карточке просмотра и меняется в редакторе панели; неиспользуемый `handleSizeChange` удалён.
- **Постоянная строка-шаблон**: кнопка «Добавить строку из базовой панели» и Popover-пикер удалены. Вместо них первая строка таблицы всегда пустая (`id: "template:"`) и содержит селектор «Базовая панель для новой строки». После выбора панели под ней появляется строка `template:{panelId}` (подсказки «Сначала выберите фактуру», отключённые переключатели), а её дубликат из основного списка скрывается. Выбор фактуры сохраняет строку через существующий row-endpoint; удаление шаблона сбрасывает выбор без удаления панели. Состояние `draftRows`/`draftPickerOpen` заменено на `templatePanelId: string | null`; все guard-проверки переведены с префикса `draft:` на `template:`.
- **Drawer получает свежую панель**: `displayPreviewPanel = panelMap.get(previewPanel.id) ?? previewPanel` — после PATCH галереи фото обновляются без переоткрытия.
