# Рекомендации для варианта исполнения

## Цель

Добавить в административную таблицу каталога отдельную колонку «Рекомендации» между «Фото в дизайне» и «Активен».

Каждый конкретный вариант исполнения хранит собственный массив `recommendation_image_paths`. Он не смешивается с:

- `image_paths` — товарные фотографии исполнения;
- `design_image_paths` — фотографии исполнения в интерьере;
- `recommendation_image_paths` — фотографии рекомендаций для выбранного исполнения.

## Интерфейс

- В таблице «Варианты панелей» отображаются миниатюры рекомендаций и пунктирная кнопка «+» в стиле колонки «Фото в дизайне».
- Отдельные вкладки «Варианты исполнений», «Фото в дизайне» и «Рекомендации» используют один источник — строки `panel_variants`.
- Вариант исполнения во всех трёх вкладках представлен товарной миниатюрой и названием, без вывода технического UUID.
- Во вкладке «Варианты исполнений» удалена дублирующая колонка: товарная миниатюра является самим вариантом исполнения.
- Вкладка «Фото в дизайне» показывает миниатюру исполнения и отдельную галерею `design_image_paths`.
- Вкладка «Рекомендации» показывает данные `recommendation_image_paths`, уже привязанные в таблице «Варианты панелей».
- Нажатие на миниатюру, «+» или редактирование открывает редактор соответствующей галереи нужного исполнения.
- В модалке можно загрузить и удалить рекомендации; сохранение обновляет только `recommendation_image_paths` выбранного варианта.

## Хранение и API

- PostgreSQL: `panel_variants.recommendation_image_paths JSON NOT NULL DEFAULT []`.
- Admin create/PATCH и public/admin responses передают это поле независимо от остальных галерей.
- Загрузка использует существующий S3 pipeline и привязку к `variant_id`.
