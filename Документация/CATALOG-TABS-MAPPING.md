# Вкладки и маршрутизация записей каталога

Запрос: базовые формы → panels; текстуры → textures; варианты исполнений → panel_variants; фото в дизайне → design_image_paths конкретного variant_id.

Вкладки executions и images используют один AdminExecutionsPage и существующий API panel-variants, общие редакторы создания/изменения и кеш TanStack Query. images больше не показывает несвязанный справочник комбинаций. Старые изображения текстур сохранены во вкладке texture-images; прежние mono-images/combinations URL ведут туда. Никакие записи не мигрируются и не копируются.

Фильтры: базовая форма, текстура, активность, поиск; пагинация, обновление, сброс, создание/редактирование/удаление. Во вкладке фото удаление отдельного фото выполняется редактором, не удалением всего исполнения.

Исправление таблицы: название «Базовые формы»; выбор миниатюры использует тот же отфильтрованный список исполнений, что отображение (пустое image_paths больше не смещает индекс).
