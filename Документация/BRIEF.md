# Wonder Wow Wall — Краткий Brief

## Что это?

**Wonder Wow Wall** — B2C веб-приложение (интернет-магазин) для продажи модульных стеновых панелей с возможностью визуального проектирования и подписки на обновления дизайнов.

## Продукт

### Суть предложения
- **Базовые панели** (3 размера: 30×30, 30×60, 60×60 см) — крепятся на стену один раз
- **Накладки с дизайном** — магнитное крепление, легко менять, единая цена **1 200 ₽**
- **Подписка** — ежемесячное обновление накладок без дополнительной платы

### Бизнес-модель

| Компонент | Цена | Описание |
|-----------|------|----------|
| Панель 30×30 | 890 ₽ | Базовая стеновая пластина |
| Панель 30×60 | 1 490 ₽ | Базовая стеновая пластина |
| Панель 60×60 | 2 490 ₽ | Базовая стеновая пластина |

| Подписка Business | 19 900 ₽/мес | Безлимит накладок |

## Целевая аудитория

- Дизайнеры интерьеров
- Владельцы квартир/домов, желающие обновить стены
- Арендаторы, которые хотят временное решение без повреждения стен

## Единый язык (Ubiquitous Language)

| Термин | Описание |
|--------|----------|
| **Накладка** (overlay) | Сменный дизайн на магнитном креплении |
| **Панель** (panel) | Базовая стеновая пластина (30×30, 30×60, 60×60 см) |
| **Дизайн** (design) | Визуальное оформление накладки |
| **Подписка** (subscription) | Ежемесячное обновление накладок |
| **Конструктор** (constructor) | Визуальный редактор стены (абстрактная сетка) |
| **Визуализатор** (visualizer) | Фото-редактор стены (реальное фото + ML-сегментация) |

## Ключевые фичи

### Реализовано ✅
- Каталог дизайнов с фильтрами и поиском
- Страница товара с галереей и характеристиками
- Конструктор стен — snap-to-grid, drag & drop
- Корзина (Drawer) + Checkout (3 шага)
- Подписка — выбор плана, оформление, статус в хедере
- Авторизация — вход, регистрация, восстановление пароля
- Личный кабинет — профиль, заказы, проекты, избранное
- Фото-редактор стен (Visualizer MVP)
- Backend API (FastAPI + DDD, 29 маршрутов, JWT auth)
- Тестовое покрытие (156 frontend + 97 backend тестов)

### В разработке 🚧
- ML-сегментация стен в визуализаторе
- Admin-панель для управления контентом
- Платежная интеграция
- Production deployment
