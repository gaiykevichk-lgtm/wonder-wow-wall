# Отступ конфигуратора от закреплённого меню

Запрос: на `/configurator` верхняя часть кнопок шагов скрывается под закреплённой шапкой.

Причина: шапка магазина закреплена (`position: fixed`, высота 48 px), а контейнер конфигуратора начинался с отступом 48 px (на узком экране — 24 px). Кнопки начинались у нижней границы шапки или заходили под неё.

Решение: локально для `.www-configurator` увеличен верхний padding до 80 px на широком экране и 72 px при ширине до 860 px. Отступы других страниц не изменены.

Проверки: 14 тестов конфигуратора прошли, сборка frontend прошла. Для локальной визуальной проверки временно отображён реальный компонент конфигуратора под фиксированным 48 px заголовком: снимок показал целиком видимые кнопки с зазором. Временная страница удалена.

Production: 29.09.2026 создан бэкап прежнего `index.html` и CSS в `/opt/app/deploy-backups/configurator-spacing-20260929T162026Z/`; CSS опубликован отдельным versioned asset без замены остальных ресурсов. Публичный `/configurator` и новый CSS отвечают 200, в CSS подтверждены отступы 80/72 px. Публичный снимок страницы просмотрен: все три кнопки шагов целиком видны ниже шапки без наложения. Загрузка фото и следующие шаги конфигуратора этой правкой не проверялись.
