# PRO конфигуратор
Переключатель справа вверху формы заменяет абстрактные стиль/материал на три связанных поля реального каталога: панель, текстура, исполнение. Опции с миниатюрами. Только активные связанные исполнения. Смена панели очищает текстуру/исполнение; смена текстуры очищает исполнение. Выбор обязателен до генерации. Backend проверяет связи ID, передаёт изображение конкретного исполнения и название панели в генератор. Остальные параметры сохраняются. Новые поля optional для legacy сессий.

Реализация сохранена в исходниках: switch, связанные селекты с миниатюрами, reset зависимостей, запрет неполного выбора. Backend PRO валидирует ID/активность/совместимость, берёт design_image_paths либо image_paths исполнения, добавляет имя/размер панели и исполнение в генерацию. PRO не меняет всю стену на акцент автоматически.
