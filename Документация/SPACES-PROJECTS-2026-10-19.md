# Пространство — объект, не исполнение

Запрос: убрать повторяющиеся карточки ТВ-зоны; фотографии относятся к одному объекту, не к отдельным исполнениям. Публикация на существующую VM.

Подтверждение: публичный API возвращает три строки ТВ-зоны с разными textureId1 и одинаковым названием. Старый клиент отображает каждую строку отдельно.

Решение: объединение подтвержденных трёх legacy ID в один проект на публичной стороне без удаления исходных записей и фото. Галерея объединяется с дедупликацией, все три конфигурации сохраняются для расчёта. Другие общие названия (кафе/офис) автоматически не объединять: совпадение названия не доказывает один объект. Для будущих данных поддержать явный projectId.

Стек React/Vite/Ant Design сохранён. Команды: npm run test; npm run build; npm run dev -- --host 0.0.0.0 --port 5175. VITE_BACKEND_URL — адрес read API для локальной проверки, секретов не требуется.

Статус: реализация и проверка.

Опубликовано 19.10.2026: index-CFYd_6Y1.js. 14 тестов passed, build passed.
