# Пространства: модалка и реальный каталог

Задача: удалить демонстрационные формы и фактуры из модалки «Переодеть фактуры», связывать выбранное исполнение с действительной карточкой товара.

Реализация: `frontend/src/domains/content/model/spaceCatalogOptions.ts` пересекает публичные `/api/panels`, `/api/panel-variants` и `/api/textures`: только активные товары с фотографиями исполнений и действующей фактурой. `SpacesPage.tsx` показывает реальные имена, фото фактур и варианты исполнений, при смене формы сбрасывает выбор на её собственный вариант и передаёт panel ID, variant ID, group ID и путь фото в карточку. Ошибки и отсутствие каталога видны; переход без действительной пары заблокирован. Старые демонстрационные связи из `/api/spaces` не отображаются как варианты покупки. Если нет рендера точного сочетания, исходное фото остаётся исходным; режимы визуализации заблокированы при отсутствии рендеров. `CatalogPanelPage.tsx` проверяет preselect по реальному варианту и его фотографии.

Ограничения: на 29.09 публичный каталог содержит 9 активных панелей только 300×300, 84 исполнения; большинство сцен помечены 300×600 или 600×600. Для них показываются реальные панели другого размера с явной пометкой, но не заявляется соответствие размеру сцены и не выводится ориентировочная цена для несовпадающего размера. У опубликованных 14 сцен нет ни одного render и catalogBinding, поэтому настоящее изменение фактуры *на фото той же комнаты* без загрузки реальных фотографий для каждой комбинации невозможно. Нельзя выдавать фото текстуры за фото комнаты или генерировать подмену без отдельного согласования.

Проверка: локальные тесты затронутых страниц 29 passed, TypeScript и Vite build прошли; локальный `/spaces` ответил 200, публичные API read-only подтвердили данные. Screenshot сервиса Preview завершился таймаутом, поэтому UI и пользовательский сценарий на опубликованном домене не подтверждены. Production-деплой, миграции и данные не менялись. Следующий этап: получить реальные рендеры сцен и товары нужных размеров, затем безопасно заполнить связи в админке и проверить опубликованный flow.
