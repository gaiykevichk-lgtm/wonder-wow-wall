# Управление разделом «Пространства»

Запрос: редактирование, добавление и удаление интерьерных карточек в админке.

Стек: существующие React/Vite + FastAPI + PostgreSQL. Страница `/admin/spaces` под RequireAdmin; в ней редактируются заголовок и вступление страницы, а также карточки; API `GET /api/spaces` публично, `/api/admin/spaces` GET/POST/PUT/DELETE с серверной проверкой роли ADMIN. Миграция 033 создаёт таблицу и один раз переносит 14 исходных карточек из `backend/app/seed_spaces.json`. После миграции статический JSON не является источником для сайта, чтобы удалённые карточки не возвращались. Миграция 034 добавляет хранимые настройки верхнего блока страницы. Изображения можно загрузить через существующий admin media API; ссылки на панели и варианты фактур редактируются вместе с карточкой. Кэш клиента инвалидируется после изменений в админке.

Запуск: frontend `npm run dev`, backend `uvicorn app.main:app`, перед запуском backend в окружении с PostgreSQL — `alembic upgrade head`. Переменные: `DATABASE_URL` (без локального fallback), `MEDIA_STORAGE_ROOT`, `VITE_API_URL` (необязательно). Значения и секреты здесь не хранятся.

Статус 2026-09-29: миграции 033–034 применены к PostgreSQL; backend API и frontend опубликованы на wonderwowwall.ru. 14 исходных карточек доступны в публичном API, администраторский API требует JWT. Интеграционный тест проверил добавление, изменение, удаление, редактирование заголовка и откат тестовых записей. Публичный screenshot подтвердил заголовок, фильтры и наличие карточек, но изображения на screenshot отобразились как placeholders, хотя сервер отдаёт исходные изображения с HTTP 200. Проверка через авторизованный браузер администратора не проведена (нет доступа к сеансу пользователя); прохождение живой формы редактирования не утверждается.
