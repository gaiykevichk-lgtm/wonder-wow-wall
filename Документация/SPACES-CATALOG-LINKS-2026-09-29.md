# Упрощение привязок «Пространств»

Запрос: убрать ввод технических ID и цветов из формы, показывать изображения базовых форм и исполнений, убрать демо-привязки и связать карточки с фактическим каталогом.

В каталоге реальные базовые SKU доступны через `/api/panels`, исполнения через `/api/panel-variants`, семейства фактур через `/api/textures`. Товарная страница открывается по **panel.id**, не по текстовому slug. У 14 пространств старые ссылки частично ведут на демо ID; это отдельные JSON-записи в `space_interiors.content`. Ручные hex-коды прежних фактур использовались в схеме раскладки, но больше не являются свойством актуальных исполнений каталога.

Решение в коде: модальная форма разбита на карточку, формы и исполнения; селекты с изображениями и названиями заменяют поля ID/названий/цвета. На сохранении серверный формат сохраняется, но данные форм и фактур собираются из публичного каталога, а `catalogBindings` вычисляется из выбранных исполнений. При открытии старые связи, отсутствующие в каталоге, не показываются в селектах и отображается предупреждение; до сохранения данные публичной карточки остаются неизменными. Сохранение требует выбора реальных форм и исполнений; произвольные ID не принимаются. Необязательные визуализации остаются отдельным разделом. Для новой карточки ID создаётся автоматически.

Дополнение 2026-09-29: в модальном редакторе фото сцены теперь выбирается загрузкой и показывается предпросмотром; техническое поле URL скрыто, но значение остаётся обязательным в форме и передаётся API. Из списка базовых форм только для этого редактора исключён служебный SKU «КОЛОННА» (`bbe26910-6690-4f72-8878-3a8d02b6bb88`) с нерелевантной голубой миниатюрой. Товар не удалён из общего каталога или БД. Тест проверяет отсутствие этой позиции в селекте и отсутствие видимого поля адреса.

Ограничение: миграция 14 существующих карточек без согласованного соответствия фактур и визуализаций к реальным исполнениям не может выполняться по догадке. В production ещё не удалены демо-привязки: перед изменением нужна точная карта соответствий сцены/фактуры и реального исполнения (либо явное решение владельца, что интерьеры могут потерять прежний смысл). До такой миграции карточки не редактируются без выбора реальных позиций. В проекте есть параллельные незавершённые правки, поэтому нельзя выкладывать общую сборку фронтенда вслепую.
