# Редактирование изображений текстур

## Исправленный сценарий

В `Каталог → Изображения текстур → Моно` у каждой ранее добавленной строки есть действие редактирования.

Редактор позволяет:

- изменить привязанную текстуру;
- заменить фотографию;
- сохранить изменения в существующую запись через `PATCH /api/admin/texture-combination-images/{id}`;
- сохранить исходные `id` и `created_at`.

Для режима комбинаций тот же редактор позволяет изменить обе текстуры и фотографию. Пара текстур нормализуется на backend; одинаковые текстуры остаются моно-режимом.

## Проверки

- frontend component: 3/3;
- frontend ESLint: без ошибок;
- backend unittest: 2/2;
- backend compileall: успешно;
- production build содержит маркеры редактора.

Production-данные не мигрируются: существующие изображения изменяются только после явного сохранения администратором.
