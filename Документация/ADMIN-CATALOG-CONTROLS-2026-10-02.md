# Перестановка управления строками каталога

Запрос: заменить очистку четырёх галерей метёлками, добавить недостающие очистки дизайн-фото и рекомендаций, убрать колонку Активен и перенести корзинку строки и переключатель под карандаш. Расширить вертикальный блок управления и отделить его от имени формы.

Изменён только локальный AdminPanelsPage.tsx и его component tests. Используется ClearOutlined для очистки, DeleteOutlined оставлен для удаления строки. Новые очистки PATCH-ят только design_image_paths либо recommendation_image_paths конкретных исполнений, последовательно, с подтверждением и обработкой частичного сбоя. Остальные поля не передаются. Пустые очистки disabled. Существующие обработчики удаления строки и активности перенесены без изменения API. Верхнее выравнивание трёх галерей сохранено.

Проверено: TypeScript завершён успешно, Vite build успешен. Новый компонентный тест упёрся в timeout (синхронный render/query около 102 секунд); полный набор не подтверждён. Требуется диагностика тестового render и сценарии очистки/отмены/активности перед publication.

Production не менялся в этой задаче. Не выкладывать целиком локальную сборку: имеются посторонние изменения AdminTextureCombinationsTab и расхождения server source с опубликованным bundle. Не использовать ручную модификацию минифицированного bundle для этой функциональной задачи.
