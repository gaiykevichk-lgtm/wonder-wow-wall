# Админка: промпт конфигуратора
Цель: отдельный раздел КОНФИГУРАТОР, чтение/редактирование инструкции для реальной генерации изображений.
Стек: существующий React/Ant Design, FastAPI, внешняя PostgreSQL DATABASE_URL. Без локального или in-memory fallback.
Хранение: singleton configurator_settings, миграция 039. GET/PATCH /api/admin/configurator/settings защищены get_current_admin_id. Текст 1–20000 символов, не пустой. Генерация читает настройку один раз на серию предложений и добавляет контекст стиля/материала/покрытия/комментария. Действие только на новые генерации конфигуратора, не на другие редакторы.
Команды: frontend npm run build, npx vitest run; backend python3 -m pytest. Перед публикацией alembic upgrade 039. API-ключи и параметры поставщика не раскрываются в редакторе.
Статус: реализация, тесты и проверка публикации.

## Результат
Опубликовано: миграция 039, защищённый API, чтение инструкции в реальной цепочке предложений, отдельный раздел /admin/configurator. Выкладка точечная: активные entry и AdminLayout пропатчены, новые чанки добавлены, существующие importmap-сопоставления сохранены. Бэкап /var/uploads/backup-configurator-admin-20261005.
Проверки: frontend UI test 1 passed, Vite build passed. Backend 17 passed (один прежний тест отсутствия OpenCV исключён: OpenCV установлен и ответ 200 вместо ожидаемого 503). Тест генерации проверяет наличие сохранённой инструкции в аргументе реального генератора (поставщик замокан, платная генерация не запускалась).
Production: личный браузер — редактор загрузил текущий промпт, тестовое добавление пробела сохранено, после reload осталось в БД, исходный текст восстановлен и сохранён. Screenshot просмотрен: меню/поле/кнопки без пересечений. Серверное чтение после восстановления подтвердило точный исходный текст и сборку контекста; анонимный GET возвращает 401. Preview 5188 HTTP 200, screenshot timeout — marker не выдаётся.

## Recovery 2026-10-05
Выявлено: размеры/координаты отсутствовали в промпте; подбор добирал третью фактуру из неподходящего материала (Кожа для Камень и дерево). Сессии ранее хранились в RAM и исчезали после restart. В редакторе была лишь короткая прежняя инструкция.
Изменено: полная инструкция в БД; размеры, цвет, площадь, координаты передаются; третья фактура из подходящего pool (повтор допускается с другим покрытием). Сессии сохраняются в PostgreSQL миграцией 040, фото/ответы/результаты переживают restart. Кнопка вызывает onSubmit напрямую; прежний onFinish уже был корректен, его нельзя считать доказанной причиной.
Production API воспроизведён до и после правок на фото комнаты из пользовательского скриншота. После: дерево/камень/деревянная акцентная зона, все status ready, фото и 3 результата прочитаны после restart. Коллаж просмотрен: исходная композиция частично изменена, генератор добавил тёмную балку — не считать точное совмещение доказанным. Базовая форма панели НЕ выбирается в текущей форме; panel_id ранее неверно трактовался как texture_id. Полный UI-сценарий новой генерации не воспроизведён: скрытый input не доступен upload tool по ref, состояние вкладки изменяется пользователем. Не заявлять полное исправление.
